# werk

werk is a local desktop app for one job seeker. It finds jobs that match your profile, explains the fit, writes private cover-letter drafts and keeps your CV, for macOS (Apple Silicon) and Windows 11. It never applies or contacts anyone for you.

werk is being rebuilt and has no release yet. The previous app, ununemploy, is archived on the [`legacy`](https://github.com/rengwu/ununemploy/tree/legacy) branch.

Documentation: [`docs/wiki/index.md`](docs/wiki/index.md).
