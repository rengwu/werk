Question: Where should release builds be made?
Description (Markdown source):
GitHub Actions has macOS and Windows runners and is free for public repositories. A version tag would build unsigned installers (.dmg for macOS, .exe for Windows) and draft a GitHub Release. Building locally needs both a Mac and a Windows PC for every release. I would push tags or publish releases only when you ask.
Recommendation: GitHub Actions on version tags. Every Windows build comes from a clean machine, which catches the installation and startup failures you reported before users see them.
