# werk v0.1.1

Changes since v0.1.0:

- Added **Reset werk** in Settings → General. After confirmation, it clears app data, conversations, ChatGPT sign-in and preferences, then returns to setup. Original files and exports outside werk's storage are preserved.
- Added 12 job boards and We Work Remotely's DevOps feed. The catalog now has 50 sources: 30 API/RSS feeds enabled by default and 20 optional scraped boards.
- Existing installations receive new catalog entries while keeping previous source selections, custom boards and cooldowns.
- Sources stay alphabetical when enabled or disabled, preserving scroll position and keyboard focus.
- Profile now has a full-width scrolling area and aligned toolbar, notice and sections, including at the minimum window size.

Install `werk-0.1.1-arm64.dmg` on macOS Apple Silicon or `werk-0.1.1-setup.exe` on Windows 11 x64. Updating preserves existing app data. See the [installation instructions](https://github.com/rengwu/werk/blob/v0.1.1/README.md#install).
