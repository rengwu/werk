## Question 38

```text
Round: Handoff readiness
Question: How should CV compilation be isolated on Windows?
Description (Markdown source):
LaTeX can read local files into the PDF. The assistant edits the CV source and job descriptions are untrusted, so a crafted posting could try to make your CV include a private file that you later send. macOS isolates Tectonic with the built-in `sandbox-exec` profile from the legacy app. The legacy Windows build ran Tectonic inside an AppContainer through a small Go helper, which passed Windows checks on 17 October.
Recommendation: Reuse the Go AppContainer helper, built in CI. It is the one non-TypeScript component, but it is small and already verified; the alternative can be bypassed with LaTeX macros.
Selection: single
Options: Reuse the Go AppContainer helper / No OS isolation; reject file-reading commands in the source
Selected: Something else
Notes: what are better solutions thatn to go appcontainer helper if we're gonna do it from scratch?
```
