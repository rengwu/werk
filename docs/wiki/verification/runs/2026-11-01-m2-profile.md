## Findings and limits

An assistant message CSS class initially collided with the overlay's class and covered the composer. The overlay now has its own class; the complete journey passed after the fix. Two driver selectors were corrected to target controls/status rather than exact text that included child buttons.

The real OAuth handoff exposed pi-ai's bundler-opaque Node loader. `scripts/openai-oauth.mjs` ports the legacy package-time fix and bundles only the SDK's selected OpenAI OAuth module. Authentication and refresh logic remain upstream. This is now exercised independently of simulated inference.

The first Windows CI attempt at `c04278e` found a timezone data parsing bug caused by CRLF line endings. Trimming the zone column fixed it; the complete install, shell, OAuth, profile, attachment and uninstall checks passed at `5e9f923` on Windows and macOS.

Overall Untested because the user-completed live inference check remains outstanding. No real profile facts, credentials or auth URLs are in this report. Full accessibility and native quit guards are audited in M5.
