## Findings and limits

The backup UI initially restored records successfully but could not reload because all renderer navigation was blocked. Main now permits a same-URL reload while keeping external navigation in the system browser. The accessibility audit found count/name mismatches, invalid list/tab children and insufficient CodeMirror syntax contrast; these were corrected. Tabs now implement arrow/Home/End navigation. Axe leaves some covered/ambiguous elements for manual review; it does not audit Chromium PDF viewer internals or certify screen-reader compatibility.

The macOS compiler read policy now denies file data by default and allows only its isolated work/cache, compiler binary and required system runtime/fonts. A startup probe identified a required read of the root directory itself; only that literal directory was added, not its children. Runtime isolation checks include a read outside the home/temp trees. Compilation never falls back outside the OS sandbox.

The earlier M4 CI run stalled in the shell/document driver steps without returning results. Review found fixture cleanup could wait on a native unsaved-edit prompt; cleanup now handles that prompt, and the shell driver has an explicit timeout so failures produce evidence. Cross-platform results remain unclaimed until the new CI run finishes. Manual Windows-PC release testing, repository rename, version tags and publication have not happened.
