## Limits and follow-up

Overall Untested until the Windows CI installation path is observed. Native Dock/tray clicks are outside this automated run; close/reopen uses native Electron APIs and a second OS process. M5 includes the accessibility/focus review and the user checks Windows before release.

The handoff's Electron 44.9.0 and initial Zod 4.6.5 pins had published high-severity fixes. Implementation uses the minimal patched versions 44.9.1 and 4.6.6: [Electron advisory](https://github.com/advisories/GHSA-jr5w-w6x2-84p9), [Zod advisory](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5). Fifteen moderate audit entries remain in the build-only electron-builder dependency tree; the package contains no node_modules. Reassess build tooling before release without downgrading to npm audit's suggested obsolete major version.

The remote had legacy commits newer than the local archive point. Merge `c7cf09f` preserved that public history as an ancestor while retaining the explicitly approved clean werk tree. The archive remains at `e493246`. No force push was used.
